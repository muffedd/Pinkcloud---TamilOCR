Pink Cloud - Layout Plan

AUREX'26 · Track 02 OCR · Tamil OCR tool · Vanilla JS, fully offline · designed for the 1366 × 768 demo laptop. Three pages, standard tool layout conventions, built only from tokens.css / ui.css.

The 3-page flow

→Start OCR
→Export

Back to upload (page 3 → page 1) resets the session. Each page is one screen at 1366 × 768: the page itself never scrolls; only lists and panes scroll inside their zones.

Shared layout rules (all 3 pages)

  1. One screen, no page scroll. Design at 1366 × 768 (browser chrome takes ~90px, so plan for ~1366 × 680 usable and keep key actions above y = 640).
  2. 8px spacing scale from tokens.css: 8 / 16 / 24 / 32 / 48. Panel padding 24, gap between panels 24-48, gap inside a panel 16.
  3. One primary (filled) button per page. Everything else is a secondary (outline) or ghost button.
  4. Same wordmark spot (top-left, 32 / 28 px) on every page. No navbar anywhere. The slim top bar exists on the editor only.
  5. Color never works alone. Confidence and provenance always pair color with a second cue (underline style, label, legend).
  6. Offline first. Tamil font (Noto Sans Tamil) and every icon bundled locally; no web fonts, CDNs or remote images.
  7. No modals. Transient UI is a toast or an inline popover only.

Layout rules

  1. The upload card is centered on the viewport, not on the leftover space. The help panel sits in the right gutter (48px gap) and never pushes the card off-center.
  2. Inside the card: 24px padding, 16px between dropzone, hint, file list and button. Card height is fixed so adding files never makes the page jump.
  3. One filled button on the page: Start OCR. Browse is secondary; delete is an icon button.
  4. Help panel is quieter than the card: no border weight or color that competes, no images, max 7 short lines of copy.
  5. Do NOT add: navbar, footer, hero headline, feature grid, sign-in, settings, language switch, recent-files list.

Layout rules

  1. Fixed grid at 1366: scan 580 | text 506 | rail 280, top bar 52. Panes scroll on their own; the page never scrolls.
  2. Click-to-sync: the selected word gets the same highlight in both panes (box on the scan, background on the text) and the rail row is marked.
  3. Provenance = color + underline style, confidence = 3 steps from tokens.css. The legend strip is always visible, never behind a tooltip.
  4. Top bar holds only: wordmark, page badges, Auto/Review toggle, offline badge, Export. No menus, search, avatar, tabs or zoom toolbar.
  5. Overlays are limited to the fix popover and the toast. No modals, no side drawers covering the scan.

Layout rules

  1. Single centered 880px column. Cards 3 and 4 share a row with a 24px gap; the receipt spans the full column below.
  2. Download PDF is the only filled button. TXT is outline; Back to upload is a ghost/text button.
  3. Receipt is read-only. SHA-256 on its own line in monospace, never cut with an ellipsis (64 chars fit at 13px mono).
  4. Everything fits in 768 tall with no scroll: header 72, cards 220, receipt 250, back link 48, gaps 24.
  5. Do NOT add: share, email, cloud upload, rating, format picker, DOCX, or a "new project" wizard.
