08

Usage Principles

Rules to keep the system calm and clear.

1. Hick — less choice

Show few colors at once. Gray first, color for need only.

2. Jakob — known map

Green = pass. Amber = care. Red = fault. Blue = note.

3. Von Restorff — guard orange

Orange = brand + live scan. Not for heads, trims, or all picks.

4. Orange ≠ amber

#F25A1A starts work. #B67816 asks for check. Keep them apart.

5. Softness, not pale text

Use warm base and thin edges. Keep text dark and clear.

6. Never color alone

Add icon + word: ✓ Set, ◐ Check, ✕ Fault, ● Active.

7. Provenance stays quiet

Dot + gray word. It is side data, not state.

8. Touch + sight

≥44px taps. Clear focus ring. Good at 360px width.
