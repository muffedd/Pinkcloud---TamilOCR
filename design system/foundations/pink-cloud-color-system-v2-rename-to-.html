PINK CLOUD

Color System

One orange anchor from the brand button, a warm neutral stage, and state colors picked for meaning first. Built for the OCR correction flow: upload, OCR, repair, side-by-side editing and export.

78design tokens
v2.0 · Sep 2026
Orange means actionThe brand gradient marks the main action, focus and human edits. Delete is deep orange too, always with a trash icon. Red is only an error state.
Style carries meaning, color confirms itEvery state has its own underline style, so it still reads with color blindness or in grayscale.
AA or betterText tokens pass WCAG AA (4.5:1) on white and on their soft bg. The gradient carries white text only at 19px bold+ (AA large); compact buttons use the solid step.

Brand button · source of truth

Shop

Gradient #F94612 → #FA683D, white label, 1px black-10% outline, two-layer drop shadow as specified; inner shadow scaled to this button size. White on the gradient is 3.0–3.6:1, so it is used for bold labels 19px+ only (WCAG AA large text).
