02b

Elevation, radius, motion

One elevation language for every component. Structure comes from hairlines and white space, not shadows. Motion is short and ease-out, and it is only used where it helps.

Elevation: 2 levels only

  • Flat (default): 1px solid #E6E2DE hairline or no border. Buttons, pills, toggles tracks, cards, panes, heatmap, queue rows.
  • Raised: hairline + 0 1px 2px #1E1A180F. Only on things that float above the page: fix popup, toast, toggle thumb.
  • No colored shadows, no stacked shadows, no inset shadows, no glow rings. Focus uses a 2px #F94612 outline, 2px offset.

Radius

  • 3px: word highlight.
  • 6-7px: pills, toggle thumbs, kbd.
  • 8px: buttons, inputs, toggle tracks.
  • 10px: popup, toast, cards, app frame.
  • No full-pill buttons in the editor.

Motion

  • Ease: cubic-bezier(.23,1,.32,1) (strong ease-out). Never ease-in.
  • Button press: scale(.97), 160ms.
  • Popup enters from scale(.96) + opacity 0 to 1 in 160ms, with transform-origin at the active word. It exits in 100ms.
  • Toggle thumb slides 160ms. Scroll-to-word 200ms.
  • No animation on J/K navigation or highlight changes. Keyboard actions are frequent, so they must feel instant.
  • Respect prefers-reduced-motion: drop scale, keep opacity.

Scan pane

580px wide. Viewer bg #312C29 so the paper reads as an object; page image fit-to-width with 24/32px padding. Boxes are drawn in an absolutely positioned overlay on the image. Fills stay translucent so ink is readable; strokes carry the state.

Rules

  • Box coordinates are the bbox [x, y, w, h] in pixels of the 1600px inference copy the backend serves. Draw at x × (renderedWidth / naturalWidth). The editor never guesses scale.
  • Stack order, bottom to top: region → auto → doubt → hover → active. Active wins over doubt (doubt fill hides while active).
  • Pad each box 3px outside the bbox and use radius 2 so strokes never touch ink. At rest only doubt boxes are drawn; everything else appears on hover or selection. No shadow on the page image.
  • Provenance is not drawn on the scan. The scan shows what was read; provenance lives in the text pane.
  • Repaired pages: before/after slider (ui-correction). 2px white divider, 28px round handle with ⇔, labels "Before repair" / "After" in inverse chips at the top corners. Drag follows the pointer 1:1.
  • If words[] is empty, fall back to line boxes from lines[].bbox with the line's confidence.

06

Click-to-sync, queue, hotkeys, modes

One selection model drives all three panes. There is exactly one active word (or none). Every change is instant; only scroll uses motion (160ms, ease-out).

Linkage behavior

  1. Identity. Each word gets a stable key p{page}:{lineId}:w{index} (index = 1-based position in the line's word list). All three panes look words up by this key.
  2. Click a word in the text pane → it becomes active. The scan draws the active box for the same key. If the box is outside the viewer, the viewer scrolls so the box sits at 1/3 height. If the word is in the queue, that row gets the active style and scrolls into view. The caret is placed at the end of the word.
  3. Click a box on the scan → same result, mirrored: the text pane scrolls the word into view (1/3 height) and marks it active.
  4. Click a queue row → same as clicking the word. Both panes scroll.
  5. Hover a word or box → hover style on both sides. Hover never scrolls and never changes the active word.
  6. Click empty space → nothing changes. Esc closes the popover first; a second Esc clears the active word.
  7. Page jump (badge) → clears the active word, scrolls both panes to top.
  8. Line fallback. Without words[], the unit is the line: click a line → line box active on the scan, whole line active in the text.

Review queue

  • Contents. Auto mode: doubt words only. Review mode: doubt + OK words.
  • Order. Reading order: page → line seq → word index. Predictable with J, matches the scan. (No "lowest first" sort: one order, fewer choices.)
  • Row anatomy. 3px active bar · Tamil word (Noto Sans Tamil 500 13px) · meta in Menlo 11px: L3 (+ page when the queue spans pages) + provenance if not raw · confidence right as plain Menlo 11.5px in conf-doubt color, no chip. 10/16px padding, no dividers.
  • Header. "Review" + plain "N left" text on the right (no pill). Under it: a 4px progress bar (primary gradient on neutral-100), then "x of y fixed" in 11.5px disabled text.
  • Fixed rows stay in place, strike through, chip reads "done". They leave the "left" count at once.
  • Empty. "Nothing left to review" + success check. Export stays the next step.

Keys (proposal)

JNext queue item after the active one. Wraps to the first item of the next page; at the end, a toast "Queue done".
KPrevious queue item.
↵Open the fix popover on the active word. In the popover: Accept.
EscReject / close popover, then clear selection.
J / K is the default for the build (J was suggested earlier; no other key was ever chosen). Keys never fire while focus is in a text input.
