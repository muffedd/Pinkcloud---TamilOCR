Pink Cloud Color System

v1.0 · Tamil OCR correction · anchor --pc-color-brand-500 #F25A1A · no purple

One warm orange carries the brand; everything else is built to stay out of its way. Neutrals are tinted toward the orange so the editor feels calm, and the review colors (confidence, provenance, semantic) sit on hues far from orange so nothing reads like a brand accent by accident. Every state also has a second cue (underline style, fill, or icon shape) so meaning never depends on color alone.

01Brand scale

Orange is loud, so it is used sparingly: identity at 500, actions at 600 (the lightest step where white text passes AA), hover 700, pressed 800. 50 is the soft wash for selected states.
